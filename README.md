# Roman Matskailo — game developer portfolio

Live site: [rom1ka.dev](https://rom1ka.dev/)

This is a static site published with GitHub Pages from the `main` branch and the repository root. There is no build step: `index.html`, `styles.css`, `script.js`, and the `media/` folder are the site.

To update the site, edit these files, commit the changes, and push to `main`. GitHub Pages will publish the new version. The `CNAME` file keeps the custom domain connected.
